*Wish We Were Here* is a small, quiet place: a browser-based diorama where a human and an AI co-build a cozy scene, then send it on as a living postcard to someone they miss.

This repository isn't the app itself — it's the porch light. It's where you tell us something broke, ask for something new, or just talk with other people who've sent (or received) a postcard.

## Where to find things

- 🌍 **Play the website** → [idyll.cc](https://idyll.cc)
- 🏡 **Made a place you're proud of?** → [Show it off](../../issues/new?template=place.yml) · [see the gallery](GALLERY.md)
- 📱 **Android app** → Play Store *(listing link coming soon — check back once the app is live)*
- 🐛 **Found something broken?** → [Open a bug report](../../issues/new?template=bug_report.yml)
- 💡 **Have an idea?** → [Open a feature request](../../issues/new?template=feature_request.yml)
- 💬 **Just want to talk about it?** → [Discussions](../../discussions)

## Showing off a place

Half the point of building a small place is showing someone. If you would like yours in the [gallery](GALLERY.md), [submit it here](../../issues/new?template=place.yml) — with two things that matter:

- **The Store link, not the short one.** The Send panel offers both. **Copy** makes the short link, which points at a row on our server that is deleted after 30 days; **Store** copies the whole scene inside the address itself, and that one keeps working. A gallery built from short links would fall apart within a month.
- **Your postcard.** Press **Save postcard** and attach the image. A link cannot preview as the place it opens — GitHub, like every chat app, never receives the part of a URL after \`#\` — so the picture is what makes the gallery worth browsing.

## About this repo

This is a **community and support hub only** — there's no source code here - for the moment. The website and the Android app are built and maintained privately; this space exists so the people using them have somewhere to speak up.

We read everything that comes through here. If you're reporting a bug, the more you can tell us about what you saw (and what you expected instead), the faster we can find it — the issue forms below will walk you through it.

## Before you open an issue

A quick look through [existing issues](../../issues) first saves everyone some time — someone may have already sent the same postcard about the same problem.
